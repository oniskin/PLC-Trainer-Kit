# Importing CLICK PLC Tags into a C-more HMI

This guide explains how to take the tags exported from the CLICK PLC Programming Software and import them into the C-more Programming Software for use with your HMI project.

Using the same tag names across the PLC and HMI makes the project easier to configure, troubleshoot, and maintain.

## Prerequisites

Before starting, make sure you have:

A working CLICK PLC project.

Assigned a Nickname to each PLC address that you want to use with the HMI.

Exported the CLICK PLC nicknames to a CSV file using Export Nickname.

Installed the C-more Programming Software.

Created or opened your C-more HMI project.

Configured the CLICK PLC as the controller/device for the HMI project.

For this OT Lab, the PLC and HMI communicate over Ethernet using static IP addresses:

| Device | IP Address |
|--------|------------|
| UniFi Switch Flex Mini | 192.168.1.2 |
| CLICK PLC | 192.168.1.3 |
| C-more HMI | 192.168.1.4 |

Subnet Mask: 255.255.255.0 (/24)

## Step 1 — Review the CLICK PLC Nickname Export

Locate the CSV file created using the CLICK Programming Software's Export Nickname option.

For example:

CLICK_PLC_Nicknames.csv

Open the CSV file and verify that the PLC addresses you intend to use with the HMI have descriptive nicknames.

For example:

| PLC Address | Nickname |
|-------------|----------|
| X001 | Stop Button |
| X002 | Start Button |
| X003 | eStop Reset Button |
| Y001 | Fast Run Command |
| Y002 | Stopped Light |
| Y003 | Running Light |
| Y004 | eStop Reset Light |
| C1 | HMI Stop |
| C2 | HMI Start |

Tip: If an address does not have a nickname, return to the CLICK PLC project, assign one, and export the nickname file again. Using nicknames consistently makes the HMI project significantly easier to understand.

## Step 2 — Open the C-more HMI Project

Launch the C-more Programming Software and open the project that will communicate with your CLICK PLC.

Verify that the appropriate CLICK PLC driver has already been configured for the project.

For an Ethernet-connected PLC, also verify that the PLC communication settings point to the correct PLC IP address.

For this lab:

CLICK PLC: 192.168.1.3

## Step 3 — Open the C-more Tag Database

From within the C-more project, open the Tag Name Database.

This is where C-more maintains the tag names used by HMI objects such as:

Pushbuttons

Indicator lights

Numeric displays

Numeric entry objects

Alarms

Status indicators

Other HMI controls and displays

Instead of configuring every HMI object using only PLC memory addresses, the Tag Name Database allows you to use descriptive names such as:

Stop Button
Start Button
eStop Reset Button
Fast Run Command
Stopped Light
Running Light
eStop Reset Light
HMI Stop
HMI Start


## Step 4 — Export a C-more Tag CSV as a Template

Before attempting to import your CLICK tags, it is helpful to first export a small tag database from C-more.

Create one or two sample tags in the C-more Tag Name Database and then use the C-more Export function to export those tags to a CSV file.

This gives you a CSV file containing the exact column structure and formatting expected by your version of the C-more Programming Software.

Important: The CSV file exported from CLICK is not necessarily in the same format expected by C-more. Do not assume that the CLICK Nickname CSV can be imported directly without modification.

## Step 5 — Prepare the Tags for C-more

Open both:

The CLICK Export Nickname CSV

The C-more Tag Database CSV template

Copy the required information from the CLICK export into the appropriate C-more columns.

At minimum, you will typically need to associate each descriptive tag name with its corresponding CLICK PLC address.

For example:

| C-more Tag Name | Click PLC Address |
|-----------------|-------------------|
| Stop Button | X001 |
| XStart Button | X002 |
| XeStop Reset Button | X003 |
| Fast Run Command | Y001 |
| Stopped Light | Y002 |
| Running Light | Y003 |
| eStop Reset Light |  XY004 |
| HMI Stop | C1 |
| HMI Start | C2 |

Preserve the column names, formatting, device/controller information, and other required fields generated by C-more.

Save the completed file as a new CSV file.

For example:

PLC_OT_Lab.csv

Recommendation: Keep the original CLICK export unchanged. Create a separate CSV file for the C-more import so you always have the original PLC export available for reference.

## Step 6 — Import the CSV into C-more

Return to the C-more Programming Software and open the Tag Name Database.

Use the Tag Name Database's Import function and select your prepared CSV file.

For example:

PLC_OT_Lab.csv

Complete the import process.

C-more should populate the Tag Name Database with the imported tag names and their associated PLC addresses.

## Step 7 — Verify the Imported Tags

After the import completes, review the Tag Name Database before downloading the project to the HMI.

Verify that:

Tag names imported correctly.

PLC addresses match the CLICK project.

Tags reference the correct CLICK PLC/controller.

Data types are appropriate for their intended use.

No unexpected duplicate tags were created.

No required tags are missing.

Pay particular attention to addresses that the HMI will write to, such as Start, Stop, Reset, or other control commands.

## Step 8 — Use the Tags in Your HMI Screens

You can now use the imported tags when configuring C-more screen objects.

For example, a Start button on the HMI could reference:

Start Button

rather than requiring you to remember:

X002

Likewise, an indicator showing whether the simulated motor is running could reference:

Fast Run Command

This creates a much clearer relationship between the PLC logic and the HMI interface.

## Step 9 — Download and Test

After verifying your tags:

Save the C-more project.

Connect to the C-more HMI.

Download the updated project to the HMI.

Verify communications between the HMI and CLICK PLC.

Test each HMI control and indicator against the physical OT Lab.

For this lab, try operating the system from both the physical controls and the C-more HMI.

Verify that the HMI correctly reflects the current state of the PLC and simulated motor.

## Troubleshooting

If an HMI object does not work as expected, check the tag configuration first.

Confirm that the tag points to the correct CLICK PLC address and that the C-more project is communicating with the correct PLC IP address.

Also compare the C-more Tag Name Database against the original CLICK Nickname export. A simple address mismatch can cause an HMI control or indicator to behave incorrectly.

If multiple tags are not working, verify PLC communications before troubleshooting each individual tag.

## Keeping the PLC and HMI Projects Synchronized

As you modify your OT Lab, you may add new PLC addresses or change existing nicknames.

When this happens:

Update the Nicknames in the CLICK PLC project.

Use Export Nickname to generate an updated CSV.

Update the C-more import CSV with the new or changed tags.

Import the updated tags into C-more.

Verify the tag mappings before downloading the project.

Keeping descriptive tag names consistent between the CLICK PLC and C-more HMI will make your lab much easier to understand and modify.

Lab Tip: Feel free to experiment. Add new PLC logic, create additional tags, build new C-more screens, and modify the provided project files for your own lab environment. The goal of the OT Lab is to provide a safe environment for learning how PLCs, HMIs, networking, and industrial control systems work together.
