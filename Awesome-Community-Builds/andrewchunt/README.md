# PLC Trainer Kit – Community Builds

This repository is a fork of the PLC-Trainer-Kit project created by Oren Niskin.

The original PLC Trainer Kit provides an affordable, hands-on platform for learning about industrial control systems (ICS), Programmable Logic Controllers (PLCs), Human-Machine Interfaces (HMIs), industrial networking, and Operational Technology (OT) cybersecurity using real industrial hardware.

This fork is where I will share my own builds, modifications, and projects based on the original PLC Trainer Kit.

Original Project: oniskin/PLC-Trainer-Kit

## 🚀 My First Community Build

C-more CM5 Physical HMI Build

My first contribution expands the original PLC Trainer Kit by adding a physical AutomationDirect C-more CM5-T7W HMI.

The original project includes HMI functionality as part of the learning environment. For my build, I wanted to incorporate a dedicated industrial HMI to provide an additional hands-on experience that more closely represents the PLC and HMI interaction commonly found in manufacturing and other OT environments.

The build demonstrates communication between the PLC and C-more HMI while providing physical HMI controls and visualization of the simulated industrial process.

Detailed build information, configuration instructions, project files, and other documentation are available in the dedicated project folder:

➡️ [C-more CM5 HMI Build](./C-more%20CM5%20HMI%20Build/)
